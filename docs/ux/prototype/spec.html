The commission surface

A single-operator web UI that commissions one research brief to several models, then presents the result as a claim landscape with evidence one click away. The UI reads the run record. It produces no interpretation of its own.

Agreement is model agreement. It is not verification. Every screen in this spec exists to keep that distinction legible — which is why silence, failure, and single-source claims are rendered as first-class states rather than gaps.

01 — Goals & non-goals

Goals

  • → Assemble an input set and a brief, and see exactly what will be dispatched before anything is sent.
  • → Commit to spend as an explicit, priced decision with a hard ceiling.
  • → Read a run's outcome as canonical claims × models, grouped by epistemic status.
  • → Reach the verbatim span behind any score in one action.
  • → Make failure, exclusion, and silence visible inside the result — never in a log the operator must go find.

Non-goals (V0.1)

  • × No accounts, sharing, or multi-user review. One operator, one machine.
  • × No editing of claims or scores in the UI. Corrections are superseding artifacts, per AGENTS.md §5.
  • × No streaming token view. The harness consumes complete responses.
  • × No Silver or Gold review workflow. No adjudication UI, no approval gates.
  • × No OCR, no re-extraction retry, no per-file extraction settings.
  • × No mobile layout. Minimum viewport 1280px.

04 — The claim landscape

The core object of the product. One row per canonical claim, one column per dispatched model, grouped by epistemic status. Build this before the report tab — the report is generated from this data and is the lesser surface.

Cell states

A stance sign and a strength magnitude. Tint alpha encodes strength: 0.20 at ±3, 0.13 at ±2, 0.07 at ±1. Cobalt for support, orange for contradiction. Nothing else carries colour.

{{ cs.label }} {{ cs.desc }}

The distinction between — and ✕ is the single most important detail in this spec. A silent model made an observation; a failed model made none. Collapsing them fabricates coverage.

Group taxonomy

Assigned by the analysis layer, not the UI. The UI renders the label it is given and filters on it. Order is fixed — consensus first, unaddressed last. A claim qualifying for two groups takes the disagreement label: split beats coverage.

Copy register

Declarative and compressed. State the limit, then trust the reader. "No time remaining is shown, because none is known." Never hedge, never apologise, never use an exclamation mark or an emoji. Uppercase belongs in mono chrome only — never in a heading.
