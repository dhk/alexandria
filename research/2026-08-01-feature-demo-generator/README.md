# Feature Demo Generator research

This investigation evaluates RFC-0001's proposal to turn landed software
features into demo-ready artifacts by combining repository facts with a short
human product-context interview.

## Status

The Bronze multi-model commission completed as `r-2026-0801-02`. Its
comparative synthesis concludes that the plausible wedge is narrow:
merge-triggered repository interrogation, a structured PM interview, and a
provenance-bearing demo specification. This is preliminary directional research,
not market validation: the run did not have live web access, so current
competitor capabilities, market size, and willingness to pay remain unverified.

## Run history

- `r-2026-0801-01` failed before producing research output because OpenRouter
  evaluated the provider-default 65,536-token maximum against the API key's
  weekly limit. Its safe run metadata is retained, but raw provider error
  envelopes are deliberately excluded because they contained private provider
  account identifiers and key-specific settings URLs.
- `r-2026-0801-02` supersedes the failed attempt. It used 12,000-token research
  limits and an 8,000-token grading limit, completed with all three research
  models, cost $0.581494, and is preserved intact under `03-runs/`.
