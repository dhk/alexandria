# Supersimple Custom Apps vs. the agent/BI dashboard landscape

Competitive-positioning investigation, opened 2026-07-29. Assurance level:
**Bronze (exploratory)** — single-source, not yet multi-model.

## What this is

Supersimple shared an unreleased feature transcript (their new "Custom
Apps") and asked for a research brief situating it against Hex, Lightdash,
Tableau, Metabase, and Sigma, plus any other comparable tools. This
investigation exists to answer that with sourced, falsifiable claims
rather than a single unstructured writeup.

## Read order

1. [`00-topic/source-material.md`](00-topic/source-material.md) — the
   transcript and product notes as given, verbatim.
2. [`01-brief/brief.md`](01-brief/brief.md) — the research questions this
   investigation answers, and how the comparison set was resolved.
3. [`03-runs/claude-2026-07-29/`](03-runs/claude-2026-07-29/) — the raw
   research pass: run metadata (provider, model, prompt, brief checksum,
   execution time, tool access) and the unedited findings output.
4. [`05-analysis/analysis.md`](05-analysis/analysis.md) — interpretation:
   differentiation assessment, positioning, and open questions. Kept
   separate from the raw run per `AGENTS.md` rule 7 ("keep generated
   interpretation separate from source evidence").

Stages `02-run-plan`, `04-normalized`, `06-synthesis`, `07-review`, and
`08-published` are intentionally absent — this is a single-source Bronze
pass, not a graded multi-model comparison. A dispatch through Alexandria's
own `begin_research` / `run_research` commission flow would add
independent model runs, a claim landscape, and a synthesis stage, but
that is a spend-gated action requiring the operator's explicit
confirmation and was not run here.

## Status

Single-source draft. Treat `05-analysis/analysis.md`'s claims as one
model's research, not verified consensus — `AGENTS.md`'s "do not treat
model agreement as factual validation" cuts the other way too: with only
one source, there is no agreement to lean on at all.
